イエバコ

家のなかの在庫を、やさしく整える。
家族みんなで「いま、なにが、どこに、どれだけ」を共有できる、シンプルな家庭在庫管理アプリです。

できること

場所 → 箱 → アイテムで整理

「キッチンの冷蔵庫の牛乳」のように、3階層で在庫を管理できます。あなたの家のレイアウトに合わせて自由にカスタマイズ可能。

iCloud で家族と共有

家族の Apple ID で同じ iCloud に同期。買い物の重複や、誰かが知らないうちに使い切ってしまう問題を防げます。

残り少なくなると自動で買い物リストへ

閾値を設定しておけば、減ったときに自動で「買うものリスト」に追加。賞味期限の近いものは通知でお知らせ。

ウィジェットと Live Activity

ホーム画面のウィジェットで在庫をひと目で確認。買い物中は Dynamic Island でチェックリストを進められます。

使い方の質問やバグ報告、機能リクエストは フィードバック から、よくある質問は ヘルプ をご覧ください。

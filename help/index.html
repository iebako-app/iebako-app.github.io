ヘルプ

よくある質問と使い方のヒントをまとめています。解決しない問題があれば フィードバックフォーム からお気軽にお問い合わせください。

基本

「場所」「箱」「アイテム」って何が違うの？

イエバコは家のなかの物を 3 階層で整理します。

  • 場所: キッチン・洗面所・寝室などの大きな空間。
  • 箱: 場所のなかにある収納単位。例: キッチンのなかの「冷蔵庫」「シンク下」「食器棚」。
  • アイテム: 箱のなかにある実物。例: 冷蔵庫のなかの「牛乳」「卵」。

あなたの家のレイアウトに合わせて自由に作れます。

場所や箱はあとから名前を変えられますか？

はい。各画面で対象を長押し、または編集ボタンから名前・アイコン・並び順をいつでも変更できます。

削除したものを復元できますか？

削除した場所・箱・アイテムは 30 日間ゴミ箱に保管されます。設定 → データ → ゴミ箱から復元できます。30 日経過すると完全に削除されます。

iCloud 同期

家族とデータを共有するには？

共有したい家族のデバイスで、同じ Apple ID で iCloud にサインインしてください。同じ Apple ID 内であれば自動的に同期されます。

※ 別々の Apple ID 間での共有（ファミリー共有）には現在対応していません。今後のアップデートで対応予定です。

同期されないときは？
  • 機内モードや低電力モードがオンになっていないか確認してください。
  • 設定アプリ →〈ユーザー名〉→ iCloud → イエバコ がオンになっていることを確認してください。
  • アプリ内のホーム上部の同期バッジをタップすると、エラー詳細と手動再試行ができます。

通知

どんなときに通知が来ますか？
  • 賞味期限: 期限の 3 日前 / 1 日前 / 当日にお知らせします。
  • 在庫減少: アイテムごとに設定した「閾値」を下回ったときに通知します。
  • スナップショット完了: 日次の自動バックアップが完了したときに通知します（オプション）。

通知のオン・オフは設定 → 通知 から調整できます。

Pro プラン

無料版と Pro 版の違いは？

無料版には以下の制限があります:

  • 場所: 最大 3 個
  • 箱: 1 つの場所あたり最大 5 個
  • アイテム: 全体で最大 50 個
  • 広告が表示される

Pro 版では上記の制限と広告がなくなり、すべての機能を無制限に使えます。

Pro プランの解約方法は？

iPhone の 設定アプリ → 〈ユーザー名〉→ サブスクリプション → イエバコ から、自動更新を停止できます。期間終了までは Pro 機能を引き続きご利用いただけます。

機種変更したら Pro が消えました

新しい端末で同じ Apple ID を使っていれば、設定 → Pro プラン → 「購入を復元」をタップすると Pro が復活します。

データのバックアップ

データを書き出したい / 別のアプリに移したい

設定 → データ → エクスポートから、CSV または JSON 形式で全データを書き出せます。Files アプリ・メール・他アプリに送れます。

CSV を取り込むには？

設定 → データ → CSV インポートから、所定のフォーマットの CSV ファイルを取り込めます。フォーマットの詳細はインポート画面に記載されています。

スナップショットって何？

毎日 1 回、その時点の在庫データのスナップショットを iCloud Drive に自動保存する機能です。万が一データが消えた場合でも、過去のスナップショットから復元できます。

設定 → データ → スナップショットから一覧を確認・復元できます。

ウィジェットと Live Activity

ホーム画面ウィジェットを追加したい

ホーム画面を長押し → 左上の「+」ボタン → 「イエバコ」を検索 → サイズを選んで追加できます。場所サマリと買い物リストの 2 種類があります。

「買い物モード」って？

買い物リストの画面で「買い物モード ON」をタップすると、Live Activity（Dynamic Island およびロック画面）が起動し、買い物の進捗をひと目で確認できます。チェックを進めると Activity も連動して更新されます。

その他

ダークモードに対応していますか？

はい。OS の設定に追従するほか、設定 → 外観から強制的に Light / Dark を選ぶこともできます。

Siri から操作できますか？

はい。以下のフレーズが使えます:

  • 「イエバコで在庫を確認」
  • 「イエバコで買い物リスト」
  • 「イエバコで補充」
  • 「イエバコで賞味期限を確認」
  • 「イエバコで買い物モード」
